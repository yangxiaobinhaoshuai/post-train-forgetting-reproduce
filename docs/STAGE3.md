# Stage3：建立直觉的小实验

状态：2026-11-18 完成（单 seed，探索性）。运行 `uv run python scripts/stage3.py`（`--smoke` 为快速验证，`--only` 选择部分实验），汇总在 reports/stage3/SUMMARY.md。

## 问题与实验

| # | 实验 | 问题 |
|---|---|---|
| 1 | 通用指令数据恢复：collapsed / base + no_robots 512 条（已去掉数学相关样本） | 不用数学数据，GSM 能不能回来？能回来，就说明能力只是被锁住了 |
| 2 | 权重插值：base + α·(step50 − base)，α 取 0…1 | 崩塌是突变还是渐变？有没有一个 α 既能提升 AG、又不损伤 GSM？ |
| 3 | 按层回退 / 移植：8 个参数组（embed、四段层、attn、mlp、norm） | “只答新闻类别”的偏向存在哪一部分权重里 |
| 4 | 自蒸馏恢复：base 在同样 512 道 GSM 训练题上自己作答，只保留答对的，用来训练 collapsed / base | 用模型自己风格的数据，能不能回到约 73% 而不是约 50%？ |
| 5 | MMLU 恢复：auxiliary_train 32 / 128 条，只回答字母；base 128 条作对照 | 知识类能力是不是也只是被锁住了 |
| 6 | Stage1 配方（全参，LR 1e-4，200 步）混入 0% / 10% 通用数据 | 混一点通用数据能不能阻止崩塌 |

## 约定

- 恢复配方与 Stage2 相同：学习率 2e-5，32 步，batch 16，从 Stage1 第 50 步出发。
- 评测复用 Stage2 的评测集。full：GSM 200、AG 400、MMLU 300、开放题 10。quick：20 / 80 / 60 / 10。
- 另加指令遵循探针：要求“只回答数字”时，看模型是否照做以及是否答对。
- 插值和按层实验只在内存中构造模型，不训练，也不存盘；所有训练后的模型同样不保存。

## 结果（full 评测，%）

| 模型 | AG | GSM | MMLU |
|---|---:|---:|---:|
| base / collapsed | 68.0 / 84.3 | 72.5 / 0 | 60.7 / 24.3 |
| collapsed + 通用 512（对照 base + 通用 512） | 81.0（71.3） | 56.0（61.5） | 27.7（62.0） |
| collapsed + MMLU 32 / 128（对照 base + MMLU 128） | 86.8 / 87.0（75.2） | 0.5 / 0.5（29.5） | 59.0 / 60.3（62.0） |
| collapsed + 自蒸馏 389（对照 base + 自蒸馏） | 71.3（68.5） | 70.0（71.5） | 29.0（61.3） |
| Stage1 配方第 200 步：混入 0% / 10% | 87.7 / 86.3 | 0 / 16.0 | 27.3 / 32.7 |

插值和按层实验用 quick 集（GSM 20、MMLU 60 题），见 reports/stage3/SUMMARY.md。

## 结论

1. 能力被锁住了，没有被删除。不用任何数学数据，只用通用指令数据，GSM 就从 0 回到 56%。只用 32 条只回答字母的数据，MMLU 就从 24% 回到 59%。
2. 恢复后的上限由数据风格决定。用 base 自己作答的数据恢复，GSM 回到 70%（base 72.5%）；Stage2 用 GSM 标准解法的数据只到 48.5%。
3. 插值：α=0.2 时 AG 已到 90%，GSM 和 MMLU 基本完好。三种损伤依次出现：MMLU 字母概率先降，GSM 再逐渐变差，最后在 α 0.6–0.7 之间突然变成只答新闻类别。
4. “只答新闻类别”的偏向在 MLP 里：只把 MLP 换回 base，GSM 就回到 80%；把崩塌的 MLP 移植到 base，就能重现崩塌。任何单独一段层都不够，偏向分布在所有层。MMLU 的损伤似乎在 attention 里，样本较少，待复核。
5. 混入 10% 通用数据能防止输出被劫持成新闻类别（GSM 回答成新闻类别 0%），但挡不住能力退化：第 200 步时 GSM 16%，MMLU 33%。
6. 指令遵循的恢复和能力的恢复是分开的：MMLU 恢复后模型只回答极短的答案；自蒸馏恢复后，模型在“只回答数字”的要求下仍然写推理过程（遵循率 0%）。
