# 格式 vs 能力探针

状态：2026-11-18 完成（单 seed）。运行 `uv run python scripts/format_probe.py`，汇总在 reports/format_probe/SUMMARY.md。

## 问题

Stage2 的 recover512 在 GSM 恢复到 48.5%。这是找回了原有数学能力，还是只学会了 `####` 格式，或者从 512 条数据中重新学会了解题？

## 设计

- 模型：base、collapsed（Stage1 step 50）、recover512、base_math512。base_math512 是同配方对照，原权重已删，按 Stage2 recovery 配方重训。
- 同样的 GSM 200 题，用 5 种答案格式评测：`####`、`\boxed{}`、“The answer is N”、只给题目、只回答数字。
- 指标：宽松准确率（取最后一个数）、格式遵循率、GSM 训练风格（输出含 `<<算式>>`）、同一格式内的逐题对错相关（phi）。
- 贪心解码，batch 16；base 在 `####` 下 71%，原 batch 1 时为 73%。

## 结果

| 模型 | `####` | `\boxed{}` | The answer is | 只给题目 | 只回答数字（遵循率） |
|---|---:|---:|---:|---:|---:|
| base | 71.0 | 76.0 | 68.5 | 73.0 | 8.5（96） |
| recover512 | 48.0 | 49.5 | 49.5 | 47.5 | 39.5（2） |
| base_math512 | 51.5 | 52.0 | 49.0 | 53.0 | 18.0（60） |

## 结论

1. 恢复的是原有能力：recover512 在前四种格式下稳定在 48–50%，与同配方对照只差 0–5 pp。它和对照的逐题对错相关 phi 为 0.45–0.51，高于两者各自和 base 的相关（0.21–0.40）。
2. 73% → 约 50% 是配方代价：没崩过的对照模型同样下降。两个训练过的模型 95% 以上的输出都用了 GSM 标准解法的 `<<算式>>` 写法，不再用 Qwen 原本更长的推理方式。
3. 指令遵循没有恢复：要求“只回答数字”时，recover512 只有 2% 照做，对照为 60%，base 为 96%。开放题仍有 2/10 回答成新闻类别，MMLU 仍然不输出字母。
