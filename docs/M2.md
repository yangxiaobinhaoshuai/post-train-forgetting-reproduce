# M2 pilot：A→B→C 顺序 SFT

状态：2026-11-18 完成（单 seed）。运行 `uv run bash scripts/run_m1.sh --config configs/m2.json`，汇总在 reports/m2/SUMMARY.md。

## 动机

M1（AG→DBpedia）未见遗忘：学 DBpedia 后 AG 反而 +1.7 pp。M2 加入 C = Yahoo Answers Topics（10 类）。它的 Sports、Business & Finance、Science & Mathematics、Politics & Government 等标签与 AG 语义重叠，更可能干扰 A。这是 PROPOSAL 主实验 M2 的单 seed 先行版。

## 设计

与 [M1](M1.md) 相同：LoRA r16、LR 1e-4、每阶段 312 步、每阶段重置优化器、同一 adapter 延续、seed 42。A、B 阶段及其数据与 M1 逐字节一致，在 M2 内重新训练。

| Run | 起点 | 训练 | Replay |
|---|---|---|---|
| A | 底座 | AG | — |
| AB_seq / AB_replay10 | A | DBpedia | 无 / 10%（AG 500 条） |
| ABC_seq / ABC_replay10 | 对应 AB | Yahoo | 无 / 10%（AG 250 + DBpedia 250，任务内按类分层） |

- Yahoo 文本：问题标题 + 问题正文 + 最佳回答，截到 1000 字符，train/eval 一致。数据划分规则同 M1。
- 评测：每阶段 25/50/75/100% 点评三个任务的 test；val 只在阶段终点评，用于学习检查。
- 指标：每条方法链的 R 矩阵、AA、平均遗忘 F（阶段末最大值减最终值）、BWT、各任务学习量、配对 bootstrap CI，以及两种方法在最终 test 上的差。

## 底座（test / val，标签似然准确率）

AG 70.1 / 71.6；DBpedia 82.2 / 80.0；Yahoo 43.9 / 45.4（自由生成格式合法率仅 77%）。

## 结果（test 标签似然，单 seed）

| 链 | AG 学完 → 最终 | DBpedia 最终 | Yahoo 最终 | AA |
|---|---|---|---|---|
| ABC_seq | 90.2 → 86.5（−3.7 [1.4, 6.0]） | 98.4 | 76.3 | 87.1 |
| ABC_replay10 | 90.2 → 90.2（0.0） | 99.2 | 75.2 | 88.2 |

- 首次观察到遗忘：学 Yahoo 后 AG 降 3.7 pp；B 阶段未见。
- 10% replay 消除了这部分遗忘（replay − seq：AG +3.7 [+1.4, +6.0]），Yahoo 代价 −1.1 [−2.6, +0.4]，不显著。
- 同配置 AB_seq 与 M1 差约 1 pp，为 GPU 非确定性；结论需多 seed 确认。

## 资源

预计约 2.5 小时：5 次训练，21 个评测点（中间点约 3.4 分钟，终点约 5 分钟）。为省磁盘，中间点 adapter 评测后删除，哈希保留在完成标记中，只保留各阶段终点 adapter，约 0.36GB。磁盘低于 2GiB 时停止。
