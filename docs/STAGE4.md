# Stage4：RL vs SFT 的遗忘对照

状态：2026-11-18 完成（单 seed，探索性）。运行 `uv run python scripts/stage4.py`（`--smoke` 为快速验证，`--arms` 选择部分臂），汇总在 reports/stage4/SUMMARY.md。

## 问题

在同一任务（AG News）、同一起点（base）、同一训练循环和步数下，只换损失函数和数据来源，比较遗忘。对应以下直觉：

1. 数据来自模型自己（on-policy）还是外部：sft_gold vs sft_self / rft / grpo。
2. 梯度落在哪些 token 上：记录被训练 token 的惊讶度（−log p）。
3. 更新的密度：比较相对更新量和发生改变的参数比例。
4. RL 的遗忘形态：GSM pass@1 / pass@8、答案多样性、首 token 熵。
5. 用 KL 把模型拉住：grpo_kl。
6. 遗忘能否用“新任务分布上的 KL”预测：画 GSM 对 KL 的散点图。

## 设计

| 臂 | 学习率 | 数据 / 损失 |
|---|---|---|
| sft_gold | 1e-4 / 1e-5 | gold 标签 + EOS，只在标签上算损失（即 Stage1 配方） |
| sft_self | 1e-4 | base 用 T=1 采样一次，只保留答对的（离线 on-policy） |
| grpo | 1e-4 / 1e-5 | 每个提示采样 8 条；奖励为是否与标签完全一致；组内标准化优势；不加 KL |
| grpo_kl | 1e-5 | 同 grpo，加 β=0.05 的 k3 KL 惩罚，参照 base |
| rft | 1e-5 | 在线拒绝采样：每步从当前模型采样 8 条，只在答对的样本上做 SFT |

- 公共设置：全参、bf16、AdamW（weight decay 0.01）、梯度裁剪 1.0、warmup 30 步后恒定学习率、200 步、每步 16 个提示（各臂的提示顺序相同）。
- RL 采样用纯温度 T=1，关闭 top-p、top-k 和重复惩罚，最多 16 个 token。每批数据只做一次梯度更新，所以没有重要性比率，也不需要 clip。
- 手写实现，没有用 trl，以免改动 uv.lock。

## 探针

- 第 10 / 25 / 50 / 100 / 200 步：
  - quick 评测：AG、GSM、MMLU、开放题、只回答数字。
  - 对 base 的精确序列 KL：沿模型自己采样的路径逐位置计算全词表 KL，分别在 AG 提示（64 条）和 GSM 提示（32 条）上。
  - 首 token 熵。
- 终点额外做：
  - full 评测。
  - GSM 50 题 × 8 次采样（T=0.7）：pass@1、pass@8、不同答案数。
  - 按组统计的相对更新量和改变参数比例。参数是 bf16，低于精度的更新会被舍入成 0，所以改变比例偏低。

| base | 68.0 | 72.5 | 60.7 | 0.57 | 0 | 0 | 77 / 100 |
| sft_gold 1e-4 | 89.5 | 0 | 26.3 | ≈0 | 1.12 | 35.5 | 0 / 0 |

## 结论

1. 学习率决定一切，方法几乎无关。1e-4 下三种方法全部崩塌（GSM 0，MMLU 约 26%），包括 GRPO 和 sft_self；1e-5 下四种方法 AG 都到 85–90%，GSM 和 MMLU 都基本不掉。“RL 遗忘更少”在这里没有出现。
2. on-policy 数据不防崩塌。sft_self 和 rft 训练的都是模型本来就会输出的 token（rft 惊讶度只有 0.08），但 sft_self 在 1e-4 下照样崩塌。在本任务里 gold 和自采样的输出都是一个类别词，格式相同，所以差别本来就小。崩塌的来源是“大步长 × 极窄的输出”，而不是数据来自外部。
3. 唯一看到 on-policy 优势的是 MMLU 字母概率（保留 0.19–0.28，sft_gold 只剩 0.08）。这是软的分布变化，准确率上看不出来。
4. 新任务上的 KL 不能预测遗忘。sft_self 1e-4 的 KL·AG 最小（0.73），GSM 却是 0；旧任务上的 KL 才与遗忘一致，但这近乎同义反复。
5. 更新稀疏度不随方法变化：同一学习率下各臂的相对更新量和改变比例几乎相同（受 bf16 舍入限制）。
6. RL 的分布收窄只出现在训练任务上（AG 首 token 熵 0.3 → 0.03），没有波及 GSM 的 pass@8 和答案多样性。
7. KL 惩罚把 KL·AG 减半，代价是 AG 少 3.5 个点；在 1e-5 这种本来就不遗忘的设定下，它对 GSM 没有可见收益。
8. grpo 1e-4 是失败的 RL：奖励没有上升（0.63 → 0.66），熵塌到 0.01，AG 没学会，但旧能力照样被毁。即使不学会新任务，过大的更新也会造成遗忘。
