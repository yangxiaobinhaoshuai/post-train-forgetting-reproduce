# Stage5：长输出任务上的 RL vs SFT，以及临界学习率

状态：2026-11-18 完成（单 seed，探索性）。运行 `uv run python scripts/stage5.py`（`--smoke` 为快速验证，`--parts gsm ag` 选择部分），汇总在 reports/stage5/SUMMARY.md。

## 问题

Stage4 的局限：AG 的输出只有一个类别词，gold 和模型自己的输出格式完全相同，所以“数据来自外部还是模型自己”这个变量没有被真正检验到。另外 1e-4 下全部崩塌、1e-5 下全部正常，方法间的差异可能藏在两者之间。

- A：换成 GSM8K。gold 解答带 `<<…>>` 计算标注和 `####`，与模型自己的解题风格差别很大。看提升数学之后，其它能力和指令遵循掉多少。
- B：AG 上用 3e-5，看同一学习率下是否有的方法崩、有的不崩。

## 设计

| 部分 | 臂 | 学习率 | 说明 |
|---|---|---|---|
| A（GSM） | sft_gold / sft_self / rft / grpo | 2e-5（同 Stage2 配方） | 512 道训练题，64 步 × 16 题（2 轮）；RL 每题采样 8 条、最多 512 token；奖励为最后一个数字是否等于答案；sft_self 为 base 在 T=1 下答对的样本 |
| B（AG） | sft_gold / sft_self / grpo / rft | 3e-5 | 直接复用 Stage4 的代码和设置（200 步），只改学习率 |

- A 的探针：第 8 / 16 / 32 / 64 步做 quick 评测和对 base 的 KL；终点做 full 评测、GSM pass@1 / pass@8、输出风格（`<<>>` 比例、平均长度）、更新幅度。
- 遗忘看：AG、MMLU（准确率和字母概率）、“只回答数字”的遵循率。
- base 的参照探针与 Stage4 相同，直接复制。

## 结果

A（GSM 训练，full 评测 %）：

| 臂 | GSM | pass@1 / pass@8 | `<<>>` 比例 / 输出长度 | AG | MMLU | 字母概率 | 只回答数字遵循 | KL·GSM |
|---|---:|---|---|---:|---:|---:|---:|---:|
| base | 72.5 | 77 / 100 | 0 / 290 | 68.0 | 60.7 | 0.57 | 98 | 0 |
| sft_gold | 49.5 | 56 / 90 | 100 / 112 | 67.2 | 62.3 | 0.42 | 59 | 20.8 |
| sft_self | 70.0 | 76 / 98 | 0 / 288 | 70.5 | 61.0 | 0.65 | 95 | 3.3 |
| rft | 82.0 | 80 / 98 | 0 / 128 | 70.0 | 62.0 | 0.21 | 94 | 14.8 |
| grpo | 77.5 | 81 / 96 | 0 / 254 | 71.0 | 56.3 | 0.13 | 37 | 16.1 |

B（AG，3e-5）：四种方法都没有崩塌，AG 82–90%，GSM 69–71%，MMLU 62–64%。但 MMLU 字母概率全部塌到 0.002 以下（1e-5 时 RL 还保留 0.2）；KL·GSM：sft_gold 4.6，其余 1.3–1.9。完整表格见 reports/stage5/SUMMARY.md。

## 结论

1. 风格差异大时，off-policy 的 SFT 伤害的首先是训练任务本身。sft_gold 让模型 100% 改用 GSM8K 标注风格，输出缩短到 112 token，GSM 反而从 72.5 降到 49.5（与 Stage2 一致）。on-policy 的三种方法都保持了原风格。
2. 在线 on-policy 才有提升：rft 82%、grpo 77.5%；离线的 sft_self 基本不动（70%）。base 只有 4/200 题因 512 token 上限被截断，所以 rft 的提升不是“学会写短一点”造成的。
3. on-policy 不等于不遗忘。grpo 的“只回答数字”遵循率从 98% 掉到 37%（比 sft_gold 的 59% 更差），MMLU 掉 4 个点、字母概率掉到 0.13。RL 强化了“总是写推理过程”，压过了与之冲突的指令（已核对输出：grpo 的 63 条不遵循都是完整的推理过程，不是正则误判）。rft 在各方面都最好。单 seed，待复核。
4. 新任务上的 KL 不能给遗忘排序：grpo 的 KL·GSM 比 sft_gold 小，遵循率却掉得更多。
5. pass@k 有轻微收窄：grpo pass@1 最高（81）、pass@8 从 100 降到 96、不同答案数最少。只有 50 题，属于迹象。
6. AG 上的崩塌阈值在 3e-5 和 1e-4 之间，四种方法的阈值看不出差别。3e-5 下准确率都正常，但 MMLU 字母概率都已塌掉，说明软性损伤先于硬崩塌出现，且与方法无关；只有旧任务分布上的漂移（KL·GSM）是 sft_gold 最大。
